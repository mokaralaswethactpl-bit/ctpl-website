# CTPL — White Glass + Royal Purple UI (November 2026)

Based on the approved white-card reference.

* Primary accent and icon colour: **#7C3AED**.
* Cards: **white**, translucent glass-like treatment, soft purple borders and shadow.
* Background: off-white and pale lavender; typography uses **Plus Jakarta Sans**, with system fallbacks. The font is loaded from Google Fonts when online.
* Navigation: translucent blurred white header with purple active links; popovers are white glass.
* Homepage: warm lavender hero, compact 4-line service descriptions, white cards, purple CTAs and icons.
* Interactions: subtle hover lift, scroll reveal (existing directive), keyboard focus and reduced-motion support.

Original content, routes, SVGs and image assets were left in place. The build must be run in the user's local environment to check layout visually.

To run: `npm ci` then `npx ng serve`.
