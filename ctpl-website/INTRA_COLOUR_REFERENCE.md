# CTPL INTRA Reference Colour System

Based on the screenshot supplied 25 Nov 2026. Near-white surfaces, blue/cyan actions, and purple/lavender accents.

- Main background `#F8FAFF`
- White navigation/cards `#FFFFFF`
- Secondary surface `#F1F7FF`
- Selected/hover background `#EDF5FF`
- Primary blue `#0877E8`
- Secondary blue `#2563EB`
- Cyan `#06B6D4`
- Purple accent `#885CF6`
- Lavender `#A78BFA`
- Main text `#0F1830`
- Secondary text `#475569`
- Borders `#DCE7F2`

Main actions use cyan-to-blue gradient. Cards are white, with subtle blue shadows, purple icons, and a lavender border on hover. Existing photo assets and text retained. Dark mode retains distinct dark surfaces.

Run `npm ci` and `npx ng serve` on Windows. A full browser QA pass is recommended before production publication.
